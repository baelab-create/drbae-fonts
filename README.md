# drbae-fonts

닥터배·배랩 사이트 공통 웹폰트. GitHub Pages: https://baelab-create.github.io/drbae-fonts/

- `gmarket.css` — G마켓 산스 Light(300)·Medium(500)·Bold(700) `@font-face`
- `web/*.woff2` — 원본 OTF(G마켓 배포본)를 WOFF2 로 변환

```html
<link rel="stylesheet" href="https://baelab-create.github.io/drbae-fonts/gmarket.css">
<style>body{font-family:"Gmarket Sans","Noto Sans KR",system-ui,sans-serif}</style>
```

G마켓 산스 서체는 지마켓이 무료 배포하며 개인·기업의 상업적 이용이 가능합니다(서체 자체의 유료 판매 금지).
